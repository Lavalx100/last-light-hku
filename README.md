# Last Light: HKU

A first-person exploration game set in a darkened recreation of the HKU Main Building. Explore the building, complete four console mini-games, collect relics, and reach the exit.

## Open the Unity project

1. Install Unity Editor **6000.3.6f1**.
2. Add the `LastLightHKU` folder in Unity Hub.
3. Open `Assets/Scenes/MainMenu.unity` to start from the title screen. `Assets/Scenes/MainGame.unity` is the gameplay scene.

The original project also used Unity Asset Store packs and HKU merchandise scans. Their source files have been left out of this public source copy. The scenes can therefore show missing assets until you import separately licensed packs and supply replacement collectible models. See [CREDITS.md](CREDITS.md) for the exact dependencies, attribution, and license notes.

## Controls

- **W / A / S / D** — Move
- **Tab** — Open the phone
- **F** — Toggle flashlight
- **E** — Interact
- **Esc** — Open the menu
